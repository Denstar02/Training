# Тренировки

Одностраничное приложение: турник, отжимания, приседания, растяжка и свои программы.
Счётчик отжиманий и приседаний работает по камере прямо в браузере, видео никуда не отправляется.

## Как выложить на GitHub Pages

1. Создай репозиторий, например `Training`.
2. Загрузи в корень все файлы из этой папки: `index.html`, `cam.js`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту страница будет доступна по адресу `https://<логин>.github.io/Training/`.

## Установка на телефон

- Android, Chrome: открой адрес и нажми «Установить приложение» в блоке внизу страницы.
- iPhone, Safari: «Поделиться» → «На экран „Домой“».

После установки приложение запускается с иконки, работает офлайн и обновляется само,
когда ты открываешь его с интернетом.

## Обновление версии

Залей новый `index.html` поверх старого. Файл `cam.js` (движок счётчика по камере, около 2 МБ)
меняется редко: он грузится только когда включаешь подсчёт камерой, поэтому страница открывается быстро. При следующем открытии с интернетом
приложение покажет подсказку «Есть новая версия — обнови страницу».
Если хочешь форсировать обновление у всех, поменяй номер кэша в `sw.js`:
`const CACHE = "training-v2";`

## Свой сервер

В папке `server/` — всё для работы на собственном VPS с адресом denstar-train.ru: установка одной командой, перенос данных из Supabase, ежедневные копии базы. Подробности — в `server/README.md`.

Один и тот же `index.html` работает везде: на denstar-train.ru он ходит в свой сервер, на GitHub Pages и в предпросмотре — в Supabase. С версии 2.07 в начале скрипта стоит `var MOVED_TO = "https://denstar-train.ru"` — копии на GitHub Pages и workers.dev перекидывают туда вместе с отметками из браузера (остаться на старом адресе: `?stay=1`).
